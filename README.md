# Realtime Chat Application

## Description
A real-time chat application that allows users to communicate instantly with each other. Built with modern web technologies.

## Features
- Real-time messaging
- User authentication
- Message history
- Online status indicators
- Typing indicators

## Installation

1. Clone the repository
```bash
git clone [your-repository-url]
cd realtime_chat
```

2. Install dependencies
```bash
# Install backend dependencies
npm install

# Install frontend dependencies
cd backend
pip install -r requirements.txt
```
### Production
```bash
# Build frontend
npm run dev

# Start production server
cd backend
python app.py
```
